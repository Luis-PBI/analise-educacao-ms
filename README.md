# Análise de Indicadores da Educação Pública de Mato Grosso do Sul

## Sobre o projeto

Este repositório reúne a documentação e os resultados visuais de um projeto acadêmico voltado à análise de indicadores educacionais de Mato Grosso do Sul, com foco em matrículas escolares e taxas de aprovação.

O estudo apresenta indicadores do período de 2019 a 2026, com análises históricas e comparações entre municípios.

## Tecnologias utilizadas

- Python
- PostgreSQL
- SQL
- Streamlit
- Plotly
- LaTeX

## Resultados apresentados

O material inclui registros visuais das seguintes análises:

- Evolução histórica das matrículas escolares.
- Comparação entre Campo Grande e Dourados.
- Municípios com maiores taxas de aprovação.
- Municípios com menores taxas de aprovação.
- Consulta aos indicadores armazenados no PostgreSQL.

## Documentação

O artigo acadêmico em LaTeX descreve a metodologia, os resultados e as limitações da análise.

**Conteúdo disponível:** arquivo LaTeX e imagens dos resultados. O código executável do dashboard e a base de dados original não estão incluídos neste repositório.
